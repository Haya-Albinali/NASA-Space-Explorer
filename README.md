# NASA-Space-Explorer

## The Project Idea:
The NASA Space Explorer is a simple application created in a way to help users explore NASA and space related information. This project facilitates a simple way to find interesting space related information and images.
## How this project helps NASA/Space:
The application aids in generating more interest in space exploration by making the information related to NASA easier and more engaging to explore.
## Technologies/ tools used:
HTML, CSS, JavaScript, GitHub, Git
## How to Run the project:
1- clone or download this repository.
2- open the project folder.
3- open the 'index.html' file in a web browser.
4- Explore the NASA Space Explorer appliaction.
